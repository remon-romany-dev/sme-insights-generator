# Theme Money

مشروع بيع إضافة ووردبريس لتوليد البوستات بالذكاء الاصطناعي، ومعاها الثيم لاحقاً كطقم واحد.

المجلد ده هو مكان الشغل. موقع SME الحالي وريبو `sme-insights` الكامل ومجلد البورتفوليو ما اتعدلوش.

## إيه اللي موجود

| المسار | المحتوى |
| --- | --- |
| `plugin-src/` | نسخة 1.0.0 كما هي من جيت هب، من غير تعديل |
| `plugin/sme-insights-generator/` | نسخة العمل 1.1.0 |
| `packages/wordpress-org/` | حزمة دليل ووردبريس |
| `packages/codecanyon/` | حزمة CodeCanyon مع شرح إنجليزي |
| `PLAN.md` | ترتيب الشغل |
| `FINDINGS.md` | مشاكل الكود وإيه اللي اتعمل فيها |
| `CHANNELS.md` | قنوات الفلوس |
| `THEME.md` | الثيم متأجل لبعد ما الإضافة تثبت |

## المصدر

- الريبو: https://github.com/remon-romany-dev/sme-insights

## قاعدة ما نبوظش الشغال

لو حقول الموضوع والكلمات فاضية، التوليد يستخدم قوائم SME القديمة (Finance و Marketing و Technology و Growth و Strategy). موقع SME يفضل يطلع نفس نوع البوستات لحد ما الإعدادات تتغير.
